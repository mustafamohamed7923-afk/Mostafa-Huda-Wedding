# دعوة زفاف Mostafa & Huda

موقع دعوة زفاف ثابت وخفيف، بتصميم Champagne & Gold ومتوافق مع شاشات الموبايل.

## محتويات الحزمة
- `index.html` — الصفحة الرئيسية.
- `styles.css` — التصميم والألوان والتجاوب مع الشاشات.
- `script.js` — العد التنازلي وزر تشغيل/إيقاف الموسيقى.
- `assets/couple-1.jpg` و`assets/couple-2.jpg` — الصورتان الأصليتان المرسلتان، دون إعادة ضغط أو تعديل.
- `assets/romantic-music.wav` — مقطوعة هادئة أصلية مولّدة خصيصًا للدعوة.

## بيانات الدعوة
- **العروسان:** Mostafa & Huda
- **التاريخ:** السبت 5 ديسمبر 2026
- **الوقت:** 7:00 مساءً بتوقيت مصر (Africa/Cairo، UTC+02:00 في هذا التاريخ)
- **المكان:** قاعة اللوتس، الرأس السوداء
- **رابط الخريطة:** https://maps.app.goo.gl/gdVt1FcN32Hj8AtQA

## النشر على GitHub Pages
1. فك ضغط ملف ZIP على جهازك.
2. أنشئ مستودعًا جديدًا على GitHub.
3. ارفع **محتويات المجلد** إلى جذر المستودع مباشرة، بحيث يكون `index.html` في المستوى الرئيسي.
4. افتح **Settings → Pages** من صفحة المستودع.
5. تحت **Build and deployment** اختر **Deploy from a branch**.
6. اختر الفرع `main` والمجلد `/ (root)` ثم اضغط **Save**.
7. بعد اكتمال النشر سيظهر رابط الموقع في صفحة Pages؛ افتحه وجرّب زر الخريطة والموسيقى.

## ملاحظات
- لا يوجد رقم هاتف أو نموذج أو زر لتأكيد الحضور.
- المعرض يحتوي على صورتين فقط.
- الموسيقى لا تبدأ تلقائيًا؛ على الزائر الضغط على زر «تشغيل الموسيقى» بسبب قيود التشغيل التلقائي في المتصفحات.
- العد التنازلي مضبوط على `2026-12-05T19:00:00+02:00`.
- الحزمة جاهزة للرفع، لكن الموقع **لم يُنشر** على GitHub Pages. يلزم تنفيذ خطوات النشر من حساب GitHub الخاص بك.
- تحميل الخطوط المخصصة يحتاج اتصالًا بالإنترنت، مع وجود خطوط بديلة.
